# /live и управление эфиром

## Адреса

- `/live` и `/live/` — общедоступный временный редирект HTTP 302 без кеширования.
- `/admin/live` — страница управления, защищённая отдельным HTTP Basic входом.
- Используйте HTTPS через существующий Traefik. HTTP-вход уже перенаправляется на HTTPS.

Если подходящей ссылки ещё нет или закреплённый файл удалён, `/live` возвращает
503 с понятным сообщением и ссылкой на главную. Вручную закреплённая ссылка не
заменяется автоматически при удалении файла: исправьте её в админке.

## Автоматический режим

FTP-сервер фиксирует только успешно завершённые загрузки (`on_file_received`).
Незавершённые передачи, просмотр сайта, создание папок, переименования и удаления
не считаются активностью. SFTP из необязательного примера не учитывается.
Учёт начинается после развёртывания: старую активность по времени файлов не восстанавливаем.

Файл должен находиться в `data/<год>/<серия>/<код>/<файл>` (вложенные файлы также
учитываются). Год — четыре ASCII-цифры; серия и код не начинаются с `.` или `_`.
Любые успешно загруженные файлы в папке учитываются, включая HTML, PDF и изображения.

Одна минута UTC с любым количеством загрузок даёт один балл. Берутся текущая
минутная корзина и предыдущие 1439: скользящие 24 часа с точностью до минуты.
Лидер — публикация с максимальным числом активных минут и существующим `index.html`.
При равенстве сохраняется предыдущий автоматический лидер, если он среди лидеров;
иначе выбирается первый по строковому идентификатору `год/серия/код`.
Ограничения на давность последней загрузки внутри окна нет.

Если кандидатов с активностью нет, сохраняется прежний автоматический адрес,
пока его HTML существует. Выбор рассчитывается при запросах и примерно раз
в 30 секунд без запросов. Полное содержимое HTML и его зависимости не проверяются:
для каталогизации действует отдельный сборщик.

Разовая массовая загрузка за две минуты даёт два балла, а регулярное обновление
в течение 40 минут — до 40. Это эвристика: при двух параллельных соревнованиях
или массовой длительной выгрузке используйте ручное закрепление.

## Ручной режим

Выберите соревнование из каталога или введите локальный путь, например
`/2026/GNP/01/`, и нажмите «Закрепить ссылку». Введённый путь имеет приоритет над
выбором из списка. Допускается существующий HTML/HTM-файл внутри публикаций;
для каталога добавляется `index.html`. Внешние URL, query/fragment и выход за
корень публикаций запрещены. Это сознательно ограничивает /live этим сервером.

Ручной режим сохраняется без срока действия. Автоматический лидер продолжает
рассчитываться и отображается отдельно. Кнопка «Вернуть автоматический режим»
сразу возвращает автоматический адрес. После POST используется redirect, поэтому
обновление страницы не отправляет форму повторно. Форма защищена CSRF-токеном;
после перезапуска сервиса открытую форму нужно обновить.

Страница показывает текущую ссылку, режим, автоматического кандидата и таблицу
активности. Данные обновляются при открытии страницы или по ссылке «Обновить данные».

## Хранение и развёртывание

SQLite хранится в volume `live-data`, отдельно от FTP-корня. FTP пишет активность,
сервис `live` читает её и сохраняет режим и адреса. Ошибка учёта активности
логируется и не отменяет успешную загрузку FTP. Настройки и активность переживают
перезапуск контейнеров. Удаление volume уничтожает это состояние.

На сервере добавьте в `.env` отдельные значения:

```dotenv
LIVE_ADMIN_USER=admin
LIVE_ADMIN_PASSWORD=<отдельный-длинный-случайный-пароль>
```

Замените значение в угловых скобках; пароль FTP повторно не используйте.
При пустом пароле админка закрыта (503), публичный автоматический `/live` работает.
Basic-вход использует диалог браузера; отдельной кнопки выхода нет, для окончания
сеанса используйте закрытие приватного окна. Пароль не записывается в каталог или HTML.

```sh
docker compose up -d --build ftp catalog live http
docker compose exec http nginx -s reload
```

`live` не публикует порт на хосте; nginx обращается к нему по внутренней Docker-сети.
FTP остаётся в существующем host network и передаёт данные через общий volume.
Основной контракт `/catalog.json` не меняется. Для главной достаточно постоянной
ссылки `https://<домен-публикаций>/live`.

Проверки после развёртывания выполняет администратор: вход, ручное закрепление,
возврат к автоматике, успешные и оборванные FTP-передачи, сохранение состояния
после перезапуска и редирект без кеширования.
